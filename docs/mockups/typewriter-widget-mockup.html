Typewriter Focus Widget

A frameless, transparent, always-on-top desktop widget — retro typewriter metaphor.

Layout

  • Paper (top): off-white sheet rolling out; holds parsed Markdown task list. Click task text to check off (animated strikethrough). Pill badge like 25m appears next to a task after a session is saved.
  • Chassis (bottom): dark body, tactile keys, small LCD display. Holds the Timekeeper.

Function

  • Paste Markdown task list → parsed into interactive checklist.
  • Timekeeper: Timer (Pomodoro, Start/Pause/Reset) or Stopwatch (count up).
  • On session end: prompt to save elapsed minutes to the active task; Discard option; <15s auto-discards.
  • LOG key: batch-sync checked tasks to Notion (PATCH Status→Done / Time (Min) / Logged At; POST create for typed tasks).
  • Drag the chassis to move the floating widget.
